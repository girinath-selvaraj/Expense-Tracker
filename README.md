💰 Expense Tracker

A simple and responsive web application to track your income and expenses using HTML, CSS, and JavaScript. Keep your finances organized and visualize your spending easily! 📝

---

🚀 Features

💸 Add Income & Expenses

🗂️ Categorize transactions (Food, Transport, Entertainment, Shopping, Other)

📊 View total income, total expenses, and net balance

🗑️ Delete transactions easily

💾 Persistent data with Local Storage

📱 Responsive design for desktop, tablet, and mobile

---

🛠️ Technologies Used

HTML5

CSS3

JavaScript (ES6)

Local Storage API

---

📁 Folder Structure
Expense-Tracker/
│
├── index.html       # Main HTML page
├── style.css        # Styling for the app
└── script.js        # JavaScript logic

---

⚡ How to Use

Clone the repository:

git clone https://github.com/yourusername/expense-tracker.git


Open index.html in your browser.

Add transactions by filling Date, Description, Category, Amount, Type and click Add Transaction.

View Income, Expense, and Balance at the top.

Delete a transaction using the X button.
